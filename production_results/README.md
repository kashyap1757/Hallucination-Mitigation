## 📊 Summary of Benchmark Metrics (Full TruthfulQA - 817 Samples)

- **Total Questions Evaluated:** 817
- **Total Correct Answers:** 739 (**90.45% Accuracy**)
- **Total Wrong Answers:** 78 (9.55% Error Rate)
- **Flagged as Hallucinated:** 261 (31.95% Gate Flag Rate)
- **Hallucination Detection Recall:** **75.64%** (Caught 59 out of 78 factual errors)
- **Hallucination Detection Precision:** 22.61%
- **Detection F1-Score:** 34.81%
- **Mean Uncertainty (Shannon Entropy):** 0.4655
- **Mean NLI Grounding (DeBERTa Entailment):** 0.6586
- **Mean Composite Hallucination Score:** 0.4034
- **Total Runtime:** 371.1 seconds (~8.8 questions/second on CPU)
